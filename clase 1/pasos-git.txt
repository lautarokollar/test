Crear un repositorio?

    git init

 

Para dar seguimiento a los archivos con git usamos..

    git add .

 

Para que los archivos a los que git da seguimiento los VERSIONE, usamos

    git commit -m 'mensaje'

 

Para renombrar la rama maestra a main 

    git branch -M main

 

Para agregar un origen remoto 

    git remote add origin direccion-del-repo

 

Para saber a que direccion remota esta conectado nuestro repo 

    git remote -v


si queremos actualizar/sincronizar nuestro repositorio local con el remoto debemos ejecutar 
  git add .
  git commit -m "comentario"
  git push 

donde dice fetch es de donde vamos a sacar la info y donde dice push es donde se va a actualizar
fetch es para traer y push para enviar

para subir el ultimo commit a la nube usamos
    git push -u origin main
